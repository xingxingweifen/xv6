在计算机体系结构中，特别是函数调用过程中，寄存器的使用可以分为两类：**caller-saved（调用者保存的寄存器）**和**callee-saved（被调用者保存的寄存器）**。这些分类影响了函数在调用过程中如何保存和恢复寄存器的值。

### ra寄存器是caller reg!!!

### 1. Caller-Saved 寄存器
**Caller-Saved**寄存器是由**调用者（Caller）**负责保存的寄存器。当函数 A 调用函数 B 时，A 可能会使用一些寄存器。如果 A 想要在 B 执行完成后继续使用这些寄存器的值，那么 A 必须在调用 B 之前将这些寄存器的值保存到栈中或其他地方，并且在 B 返回后恢复这些值。

- **职责**：调用者在调用另一个函数前保存并恢复这些寄存器。
- **影响**：这些寄存器的值在被调用的函数中可以自由修改。
- **常见寄存器**（以 x86-64 为例）：`RAX`、`RCX`、`RDX`、`R8-R11`。

### 2. Callee-Saved 寄存器
**Callee-Saved**寄存器是由**被调用者（Callee）**负责保存的寄存器。当函数 B 被调用时，如果 B 想要使用一些寄存器并且这些寄存器属于 callee-saved 的话，B 必须先保存它们的值，确保在 B 执行完返回给 A 之前，这些寄存器的值能够被恢复。

- **职责**：被调用的函数负责在修改寄存器之前保存它们的值，并在函数结束前恢复它们。
- **影响**：调用者可以假设这些寄存器在函数返回后保持不变。
- **常见寄存器**（以 x86-64 为例）：`RBX`、`RBP`、`R12-R15`。

### 使用场景
- **Caller-Saved 寄存器**适用于在函数调用中频繁使用的临时数据，因为这些寄存器的值在函数调用过程中很可能会被改变。
- **Callee-Saved 寄存器**通常用于存储一些较长期的数据，如局部变量或函数间的上下文信息。

### 总结
- **Caller-Saved**：调用者负责保存，适用于短期使用的数据。
- **Callee-Saved**：被调用者负责保存，适用于长期需要的数据。

这种区分是为了优化寄存器的使用，并减少不必要的内存操作，从而提升性能。

在 RISC-V 指令集中，寄存器的分配同样有 **caller-saved** 和 **callee-saved** 的区分。RISC-V 有 32 个通用寄存器，每个寄存器都是 64 位（在 RV64 中），这些寄存器分别用于不同的用途，并且其中一些寄存器是 caller-saved 寄存器，而另一些是 callee-saved 寄存器。

### RISC-V 寄存器命名约定
RISC-V 的通用寄存器采用数字编号 `x0` 到 `x31`，同时有符号化的名字，用于代表它们在特定场景下的用途。

### 1. Caller-Saved 寄存器
这些寄存器由**调用者**负责保存，函数调用过程中可以自由修改，但调用者如果希望这些寄存器在函数调用后保持不变，必须在调用前保存它们。

| 寄存器名称 | 别名  | 用途                        |
|------------|-------|-----------------------------|
| `x10`      | `a0`  | 函数调用的第一个参数或返回值 |
| `x11`      | `a1`  | 函数调用的第二个参数         |
| `x12`      | `a2`  | 函数调用的第三个参数         |
| `x13`      | `a3`  | 函数调用的第四个参数         |
| `x14`      | `a4`  | 函数调用的第五个参数         |
| `x15`      | `a5`  | 函数调用的第六个参数         |
| `x16`      | `a6`  | 函数调用的第七个参数         |
| `x17`      | `a7`  | 函数调用的第八个参数         |
| `x5`       | `t0`  | 临时寄存器 0                 |
| `x6`       | `t1`  | 临时寄存器 1                 |
| `x7`       | `t2`  | 临时寄存器 2                 |
| `x28`      | `t3`  | 临时寄存器 3                 |
| `x29`      | `t4`  | 临时寄存器 4                 |
| `x30`      | `t5`  | 临时寄存器 5                 |
| `x31`      | `t6`  | 临时寄存器 6                 |

这些寄存器通常用来传递函数参数或存储临时数据，调用者在函数调用之前如果不希望其值被改变，需要自己保存。

### 2. Callee-Saved 寄存器
这些寄存器由**被调用者**负责保存。被调用的函数如果使用这些寄存器，需要在使用之前保存它们的原始值，并在函数结束时恢复。

| 寄存器名称 | 别名  | 用途                      |
|------------|-------|---------------------------|
| `x1`       | `ra`  | 返回地址寄存器             |
| `x2`       | `sp`  | 栈指针寄存器               |
| `x8`       | `s0`/`fp` | 帧指针或保存寄存器 0     |
| `x9`       | `s1`  | 保存寄存器 1               |
| `x18`      | `s2`  | 保存寄存器 2               |
| `x19`      | `s3`  | 保存寄存器 3               |
| `x20`      | `s4`  | 保存寄存器 4               |
| `x21`      | `s5`  | 保存寄存器 5               |
| `x22`      | `s6`  | 保存寄存器 6               |
| `x23`      | `s7`  | 保存寄存器 7               |
| `x24`      | `s8`  | 保存寄存器 8               |
| `x25`      | `s9`  | 保存寄存器 9               |
| `x26`      | `s10` | 保存寄存器 10              |
| `x27`      | `s11` | 保存寄存器 11              |

这些寄存器通常用来保存函数的局部变量或重要的上下文信息。

### 总结
- **Caller-Saved 寄存器**：`a0-a7`（参数寄存器），`t0-t6`（临时寄存器）。
- **Callee-Saved 寄存器**：`s0-s11`（保存寄存器），`sp`（栈指针），`ra`（返回地址）。

RISC-V 的寄存器分配遵循简洁的规则，简化了函数调用过程中寄存器的管理。
